# 🚀 Vercel Deployment Guide — CohortLens / ÆGIS Retail
**Pragyan 2K26 Track 2-03: Privacy-Preserving Consumer Intelligence**

The project is **100% Vercel-ready** for full-stack deployment (Vite React Frontend + Express Serverless API Backend in a single repository).

---

## 1. Quick Summary of Vercel Settings

When importing this repository into Vercel, configure these settings:

| Setting | Value | Notes |
| :--- | :--- | :--- |
| **Framework Preset** | `Vite` | Detected automatically |
| **Root Directory** | `./` | Leave blank or default |
| **Build Command** | `npm run build` | Runs `tsc -b && vite build` |
| **Output Directory** | `dist` | Generated by Vite |
| **Install Command** | `npm install` | Default |
| **Node.js Version** | `20.x` or `22.x` | In Project Settings > General |

---

## 2. Environment Variables to Set in Vercel

In your **Vercel Project Dashboard** $\to$ **Settings** $\to$ **Environment Variables**, add:

| Name | Recommended Value | Description |
| :--- | :--- | :--- |
| `APP_ENV` | `production` | Tells the server to run in production mode |
| `HMAC_SECRET_SALT` | *(generate a strong 32+ character random string)* | Cryptographic salt for T1 $\to$ T2 phone hashing |
| `DP_EPSILON` | `0.5` | Differential privacy budget $\varepsilon$ |
| `K_ANONYMITY_THRESHOLD` | `10` | Minimum cohort suppression threshold |
| `OTP_EXPIRY_MS` | `300000` | 5-minute counter QR OTP expiry |
| `BLIND_SEND_MODE` | `simulated` | Simulated for testing, or `live` |

> [!NOTE]
> You **do not** need to set `VITE_API_URL` on Vercel! In production, the client automatically defaults to `/api`, which routes directly to the serverless function on the same domain.

## 3. How It Works on Vercel

1. **Frontend (SPA)**:
   - Built to `/dist` using `npm run build`.
   - All standard page requests (`/`, `/counter`, `/owner`, etc.) are served from `dist/index.html`.
2. **Backend (Serverless API)**:
   - Handled by [`api/index.ts`](file:///d:/TRACK-2-03-PRIVACY-PRESERVING-CONSUMER-INTELLIGENCE-FOR-RESPONSIBLE-PERSONALISATION/api/index.ts).
   - All requests to `/api/*` are rewritten by [`vercel.json`](file:///d:/TRACK-2-03-PRIVACY-PRESERVING-CONSUMER-INTELLIGENCE-FOR-RESPONSIBLE-PERSONALISATION/vercel.json) into the serverless Express function.
   - Zero configuration needed for separate server hosting.

## 4. How to Deploy

### Method A: Deploy via GitHub (Recommended)
1. Push your repository to GitHub:
   ```bash
   git add .
   git commit -m "feat: configure full-stack Vercel deployment"
   git push origin main
   ```
2. Go to [https://vercel.com/new](https://vercel.com/new).
3. Import your GitHub repository: `TRACK-2-03-PRIVACY-PRESERVING-CONSUMER-INTELLIGENCE-FOR-RESPONSIBLE-PERSONALISATION`.
4. Add the environment variables from Section 2.
5. Click **Deploy**. Vercel will build and launch your site in ~45 seconds.

### Method B: Deploy via Vercel CLI
```bash
# 1. Install Vercel CLI globally (if not installed)
npm install -g vercel

# 2. Login to Vercel
vercel login

# 3. Deploy to production
vercel --prod
```
